#### ③ **一处故意不改**：市场条目名保持全小写

`data/plugins/apfsds-dog__dsh-limbs.yml` 是上游实际存在的文件名（`gh api .../git/trees/main?recursive=1` 实查），且 `Docs/tech/踩坑录.md` #11 与 `Docs/archive/PR-HANDOFF.md` 记着事故：大小写不同的同名文件在 GitHub 上是两个文件，市场读成两条记录，**CI 全绿也照样重复上架**。

所以它不是漏改，是**上架时冻结的形态**。已在 `PROJECT_STATUS.md` 那行写明「**不改**」，防止下次有人又去「修」。
