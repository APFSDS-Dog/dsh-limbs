### 这一轮踩出来的四个真坑

| 坑 | 现象 | 根因与修法 |
|---|---|---|
| **`modelDirectories` 的形状** | 面板一挂载就 `slot entry crashed: directory.getSnapshot is not a function` | `directoryFor(sessionId)` 返回 `{ store, load(), select() }`，订阅与快照在 **`.store`** 上（模块一的座位一直这么用）。面板改成收 `store` + `select` 两个面，别把目录对象当 store |
| **`configForms` 不是 form** | 设置页 `form.subscribe is not a function` | `ctx.get('configForms')` 是**服务**，要 `forms.get(entryId)` 才拿到某条目的 `ConfigForm`（`getSnapshot`/`subscribe`/`set`）。取不到就退化成只读页并明说原因 |
| **`volatile` 字段解析出来是引用** | 直接比对 `config.context === '600k'` 永远不成立 | 官方 `plainConfig` 就是 `.get()` 一层把它摊平。测试断言按同一口径走，否则断言假红 |
| **Host 侧改了 `Config` 要重启 DSH** | 设置页显示「Host 还没提供这条插件的配置」 | Host 半侧刷新页面不重载（`ARCHITECTURE.md` 红线 10）。这正是那句提示文案要说清的事，不是 bug |
