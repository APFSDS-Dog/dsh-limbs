## excluded_paths

| 试过 / 考虑过 | 为什么排除 |
|---|---|
| 把「约 X tokens / Y KB」改成只留费用、删掉字节 | 字节数有用：它告诉你结果本身的体量，是全量读大文件这类诊断的判据。删掉等于丢一半信息，问题只在「没起名字」 |
| 尾注只加粗不改结构 | 三件事仍是同一段，扫读困难。加粗只能救一句，救不了「一段三主题」 |
| 顺手改 `README.md` 里报告章节的描述 | 它描述章节结构（六章），这次没动章节；改了反而是造第二处需同步的文案 |
| 把磁盘上那 3 份历史报告用新模板重写一遍 | 它们是**当时生成的产物**，重写等于篡改历史证据。要看新排版，点「重新复盘」覆盖当前会话那份，这才是正常路径 |
